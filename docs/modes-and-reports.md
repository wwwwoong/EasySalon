# 세 모드로 운영한다

## 마스터 모드

서버의 MASTER_USER_IDS에 등록된 개발자만 사용할 수 있습니다. 모드 버튼, URL, 브라우저 저장소로 권한을 얻을 수 없습니다.
마스터는 전체 매장을 조회하고 매장명·소개·담당 계정을 관리합니다. 각 매장의 운영 화면도 열 수 있습니다.
일반 사장님 계정은 한 매장에만 배정됩니다. 동시 배정도 데이터베이스 조건으로 차단합니다.

공통 UI 설정은 브랜드 이름, 강조색, 공지입니다. 시스템 설정은 신규 접수를 중단하는 점검 상태입니다.
앱 코드와 서버 구조를 바꾸는 개발 작업은 소스 저장소에서 진행합니다. 웹 화면에 임의 코드 실행 기능은 두지 않습니다.

## 사장님 모드

담당 매장의 메뉴·접수·통계만 조회하거나 수정합니다. 서버가 모든 비공개 요청에서 권한을 검사합니다.
일별·월별·직접 선택한 기간의 완료 고객과 시술 합계를 조회합니다. 기간은 한국 날짜 기준 양끝을 포함하고 최대 366일입니다.
완료 시술 합계는 실제 수납액·순이익이 아닙니다. 취소와 미완료 접수는 제외하며 최종 금액 정정은 합계에 반영합니다.
조합 할인은 커트와 염색 같은 조합 전체 이름으로 집계하여 메뉴별 합계와 전체 합계가 어긋나지 않게 합니다.

## 고객 모드

매장 QR로 접수하고 자신의 대기표를 조회합니다. 고객에게 공개할 메뉴·혼잡도 외에 운영 통계는 전달하지 않습니다.
현재 배포의 외부 접근은 소유자 전용 테스트 정책을 유지합니다. 일반 고객 공개 및 실제 문자 발송은 별도 단계입니다.

## 머리 길이를 선택한다

사용자가 제공한 다섯 일러스트를 길이 선택에 사용합니다.
여성은 단발·중간·긴 머리, 남성은 짧은·중간 머리를 표시합니다. 성별이나 길이를 정하기 어려우면 상담을 선택합니다.
새 메뉴에는 대상과 머리 길이 선택 여부를 설정할 수 있습니다. 기존 메뉴도 기본적으로 길이 선택을 제공합니다.
선택값은 접수 당시 사본에 보관합니다. 길이별 추가 금액과 시간을 임의로 계산하지 않습니다.

## 검증 범위를 구분한다

도메인과 실제 API 핸들러를 Node SQLite D1 호환 어댑터에서 검증합니다.
마스터 권한 위조, 일반 사장님의 다른 매장 접근, 동시 담당 배정, 기간 경계, 금액 집계와 길이 사본을 확인합니다.
브라우저 자동화 도구가 없어 실제 화면 클릭과 모바일 시각 검증은 수행하지 않았습니다.
